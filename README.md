# Запуск

```bash
./run.sh device:=/dev/ttyACM0 baudrate:=115200
```

На контроллере включите MSP.
`run.sh` сам установит зависимости, соберёт и запустит узел. При первом запуске нужны интернет и права sudo. Возможны проблемы из за отсутствующего впн, но вроде работало. Подготовка сохраняется в `.runtime/`.
